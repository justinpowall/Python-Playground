# Python Playground

A personal sandbox for learning Python. Nothing serious here — just me experimenting with the language, trying things out, and building on what I learn.

## What's in here

A simple interactive CLI app with a few mini features:

- **Personal Profile** — enter your info and get a fun summary
- **Number Games** — guess a number or check if it's prime
- **Word Tools** — reverse words, count letters, check palindromes
- **Mini Calculator** — evaluates math expressions
- **Trivia Quiz** — 5 randomized questions with a score at the end

## How to run

```bash
python main.py
```

## Structure
